# Governance

- **Maintainers** review and merge pull requests, triage issues and publish releases.
- Anyone who contributes well over time can be invited to maintain, for the whole project or for a
  service module.
- Decisions are made in the open, in issues, discussions and spec pull requests. When there is no
  agreement, the project owner decides.
- Changes to the constitution need a pull request that states the reason.
