# Security Policy

This app holds credentials for people's home servers, so please report problems privately.

**Do not open a public issue for a vulnerability.** Use
[private vulnerability reporting](https://github.com/arr-client/arr-client/security/advisories/new).

Include what is affected, how to reproduce it and the impact. Never include real API keys or
passwords.

Until 1.0, only the latest release receives fixes.
